# Enterprise-Network-Infrastructure-Project
Enterprise Network Project : Project Overview This project is a simulated enterprise network designed in Cisco Packet Tracer.   The goal of the project was to build a scalable and secure network infrastructure for an enterprise environment using VLANs, multilayer switching, routing, and DHCP services.
Technologies Used
- Cisco Packet Tracer
- VLAN Configuration
- Inter-VLAN Routing
- Multilayer Switch
- DHCP Configuration
- Static Routing
- Network Segmentation
- End Devices & Servers

## Network Design
The topology contains:
- Router
- Multilayer Core Switch
- Access Switches
- Multiple VLANs
- PCs and Servers

## Configurations Implemented
- VLAN segmentation for different departments
- Inter-VLAN communication
- DHCP for automatic IP assignment
- Routing between networks
- Gateway configuration
- Network testing using ping and troubleshooting

## Testing & Verification
The network was tested successfully by:
- Verifying IP assignment
- Testing connectivity between VLANs
- Checking routing tables
- Troubleshooting cable and interface issues

## Skills Practiced
- Enterprise network design
- Cisco CLI configuration
- Troubleshooting network issues
- IP addressing and subnetting
- Layer 2 & Layer 3 switching

## Conclusion
This project helped improve practical networking and troubleshooting skills in a real-world enterprise-style environment.  
The implementation provided hands-on experience with VLANs, routing, DHCP, and multilayer switchi
